## 線上瀏覽

GitHub Pages 啟用後，可直接使用手機或電腦瀏覽。

本GitHub頁面的螢光標記保存在目前瀏覽器。需要跨裝置時，請按「跨裝置同步」，將原有標記移到[私人同步閱讀版](https://geriatric-study-cloud.kevin8384.chatgpt.site/)，之後電腦、手機和平板以同一ChatGPT帳號登入，即可同步新增與刪除的標記。原網站標記仍保留。

首次移轉請在平常畫記的電腦瀏覽器操作「移轉標記並進入同步版」，登入新分頁並保留原分頁，直到顯示移轉完成。若瀏覽器阻擋跨分頁移轉，可下載標記備份，在同步版「標記同步」匯入一次；之後會自動同步。私人版由擁有者帳號存取，標記存於私人資料庫，不會公開到此GitHub專案。
