# 老年精神醫學學習地圖與歷屆試題詳解

這是一份以老年精神醫學甄審準備為核心的線上學習網站，內容包括：

- 16 個領域的基礎知識與學習地圖
- 107～114 年歷屆試題及考訊整理
- 完整展開的題幹與選項
- 每個選項的「正確敘述／錯誤敘述」判定與具體詳解
- 公告答案更正、送分題與疑義說明
- 個人螢光標記：選取章節或詳解文字後，按浮動「螢光標記」或右鍵開啟工具；點已標記文字可移除

## 線上瀏覽

GitHub Pages 啟用後，可直接使用手機或電腦瀏覽。

螢光標記會自動儲存在目前裝置的瀏覽器，重新整理或切換題庫篩選後仍會保留；不同裝置／瀏覽器不會自動同步，清除網站資料會一併移除個人標記。

## 使用提醒

本網站供學習與複習使用。診療、藥物、法規及考試公告仍應以最新官方資料與臨床指引為準。
